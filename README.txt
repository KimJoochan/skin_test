배포 방법
1. 이 ZIP 파일을 압축 해제합니다.
2. Vercel에 로그인한 뒤 Add New > Project를 선택합니다.
3. 이 폴더(skin-test-vercel)를 업로드하거나 Git 저장소로 연결합니다.
4. Framework Preset은 Other, Build Command와 Output Directory는 비워두고 배포합니다.
5. 생성된 https://...vercel.app 주소를 아이폰 Safari에서 열면 됩니다.

참고: 아이폰 파일 앱의 HTML 미리보기는 JavaScript 실행을 제한할 수 있습니다.
정상적인 테스트 실행은 Safari에서 배포된 웹 주소로 접속하는 것을 권장합니다.
